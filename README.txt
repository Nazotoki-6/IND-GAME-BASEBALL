MIND GAME BASEBALL Ver.2

・スマホ：縦向き前提
・タブレット：横向き前提
・2人で1台の端末を交互に渡してプレイ
・3イニング固定
・守備は1塁／2塁／3塁／ホームの4か所のうち1か所にヒットを隠す
・アウトの場合は配置を変えず、残った場所から続けて選択
・ヒットの場合のみ4か所を再配置
・1塁打／2塁打／3塁打／ホームラン
・アウト数により走者進塁ルールが変化

・同点時はノーアウト2塁から延長

・見た目を3D風（立体感のある盤面・ボタン・ベース表現）に調整

・予告ホームランは未実装（基本ルールのみ）

・プレイヤーは「かず・たけ・たろう・つよし・ゆか・りさ」の6人から先攻／後攻を選択
・同じプレイヤーを先攻と後攻に同時選択不可

・基本プレイヤーは「たけ」「ゆか」の2人
・ゲーム開始時に先攻／後攻を毎回ランダム決定

・攻撃フェーズ／守備フェーズで、背景にシルエットと「ATTACK / DEFENSE + プレイヤー名」を表示
・上部にも『○○が攻撃』『○○が守備』の役割チップを表示し、担当が一目で分かるよう調整

・攻撃＝バットを構えた打者シルエット、守備＝グラブを前に出した野手シルエットに修正
・攻撃は暖色、守備は寒色の背景グローで役割の違いを強調

・役割背景をCSS人型からSVGピクトグラム風シルエットへ差し替え
・攻撃は打者、守備はグラブを出した野手として判別しやすい形へ調整
